# Aruven (아루벤)

아는 것은 많지만 삶에서 체화가 안 되는 사람들을 위한 **실전 마음훈련** 웹사이트입니다.
코세라처럼 **코스 → 주차 → 레슨** 구조로 배우고, 무료 전자책을 읽을 수 있습니다.

> 지금은 **예시 버전(1단계)**입니다. 강의와 전자책 내용은 샘플이며, 회원·결제 기능은 아직 없습니다.

## 지금 들어 있는 기능

| 기능 | 경로 |
|---|---|
| 메인 페이지 | `/ko`, `/en` |
| 훈련 (이어하기 + 강의 + 전자책 통합, 주제/전자책 필터) | `/ko/courses` |
| 코스 소개 (커리큘럼, 배울 내용, 진도율) | `/ko/courses/knowing-to-living` |
| 레슨 학습 화면 (레슨 목록, 완료 표시, 이전/다음, 멈춤(호흡) 훈련 도구) | `/ko/courses/knowing-to-living/learn/knowledge-trap` |
| 전자책 읽기 | `/ko/library/i-know-but` |
| 마이 (연속 훈련 일수, 별자리 달력, 이어하기, 설정) | `/ko/my` |
| 한국어 / 영어 | 오른쪽 위 언어 버튼. 처음 방문 시 브라우저 언어에 맞춰 자동 이동 |

- 진도는 지금 **브라우저에만** 저장됩니다. 회원 기능을 붙이면 계정에 저장되도록 `lib/progress.ts`만 바꾸면 됩니다.
- 운영자 실명, 연락처, 주소는 화면 어디에도 표시하지 않습니다. 브랜드명 "Aruven / 아루벤"으로만 표시합니다.

## 보안 설정

`next.config.ts`에 다음 보안 헤더가 적용되어 있습니다.

- 콘텐츠 보안 정책(CSP): 허용된 출처의 스크립트와 이미지만 실행·표시
- HTTPS 강제(HSTS), 다른 사이트에 몰래 끼워넣기 방지(X-Frame-Options), 파일 형식 위장 방지(nosniff)
- 카메라, 마이크, 위치 권한 차단
- 서버 종류 노출 헤더 제거

비밀키는 코드에 넣지 않고 `.env.local` 또는 Vercel 환경변수로만 관리합니다. `.env*` 파일은 git에 올라가지 않습니다.

## 내 컴퓨터에서 실행하기

```bash
npm install
npm run dev        # http://localhost:3000 에서 확인
npm run build      # 배포용 빌드
```

## 콘텐츠 수정하기

강의와 전자책 내용은 `lib/content.ts`에 있습니다. 화면 문구(메뉴, 버튼 등)는 `lib/i18n.ts`에 있습니다.
나중에 관리자 화면을 만들면 코드 수정 없이 웹에서 강의를 추가할 수 있게 됩니다.

## 폴더 구조

```
app/[locale]/            화면(페이지)들. [locale] = ko 또는 en
  courses/               강의 목록, 코스 소개, 레슨 학습 화면
  library/               전자책 서재, 전자책 읽기
  my/                    내 학습
components/              화면 부품(헤더, 카드, 호흡 안내 등)
lib/content.ts           강의·전자책 내용
lib/i18n.ts              한/영 화면 문구
lib/progress.ts          학습 진도 저장
proxy.ts                 언어 자동 이동
next.config.ts           보안 헤더
```
